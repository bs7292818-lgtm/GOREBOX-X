# GOREBOX X — ранний Android-прототип

Это исходный Godot-проект, НЕ готовый APK и НЕ законченная игра. Сейчас есть простая 3D-площадка, игрок с камерой от третьего лица, экранные кнопки движения/прыжка/атаки, HP и тестовый манекен. Реалистичного суставного ragdoll пока нет.

## Цель проекта
Лёгкая мобильная песочница в низкополигональном стиле. Целевой размер APK — до 200 МБ; фактический размер и FPS нужно измерить на реальном устройстве.

## Сборка
Для экспорта Android нужны Godot export templates, Android SDK и корректный Android export preset. Этот репозиторий пока не содержит подписанный APK или готовые ключи подписи.

## Ограничения
- Проект пока ранний прототип.
- Нужны тесты на Tecno Spark Go 2022 (2 ГБ ОЗУ).
- Манекен пока использует упрощённую реакцию на удар, не полноценную суставную физику.
- Не включайте секреты подписи APK или пароли в публичный репозиторий.
